# Logo Guidelines

## Logo system

The Vantage Foundation Uganda logo has three lockup variants for different applications.

### Primary logo (stacked)

- **Use for:** report covers, proposals, posters, presentation title slides, formal documents, large-format signage
- **File:** `public/brand/logos/vantage-logo-primary.svg` (true vector, 14 KB)
- **Dark background variant:** `public/brand/logos/vantage-logo-primary-dark.svg`
- **Aspect:** ~4:3 (1448×1086)

### Horizontal logo

- **Use for:** website navigation, website footer, email signatures, letterheads, business cards, banners, vehicle branding
- **File:** `public/brand/logos/vantage-logo-horizontal.svg` (true vector, 14 KB)
- **Dark background variant:** `public/brand/logos/vantage-logo-horizontal-light.svg`
- **Aspect:** ~16:9 (1721×914)

### Symbol-only logo

- **Use for:** social media profile images, favicon, mobile app icon, watermark, embroidery, badges, merchandise, small-format applications
- **File:** `public/brand/logos/vantage-symbol.svg` (true vector, 2.8 KB)
- **Aspect:** 1:1 square (1000×1000 viewBox)

## Clear space

Maintain clear space on all sides equal to the height of the "V" in the symbol. No text, images, or other elements may enter this margin.

## Minimum sizes

| Application | Minimum |
|-------------|---------|
| Digital — horizontal | 32px height |
| Digital — symbol | 24px |
| Print — horizontal | 25mm width |
| Print — primary stacked | 30mm width |
| Favicon | Symbol only, never the full lockup |

## Safe backgrounds

- ✅ White
- ✅ Teal Primary (#008F95) — use the monochrome white variant
- ✅ Black (#050708) — use the monochrome white variant
- ✅ `--surface` (#F7FAFA) muted neutral

## Unsuitable backgrounds

- ❌ Busy photographic backgrounds without a solid overlay panel
- ❌ Teal Light (#DDF5F4) — insufficient contrast
- ❌ Programme accent colours — clashes with the logo's own colours
- ❌ Any background where contrast drops below 3:1

## Alignment

- In headers, align the logo left with the navigation.
- On covers, centre the primary logo vertically and horizontally.
- In email signatures, left-align with the sender's details.

## Responsive behaviour

The website header uses the horizontal lockup at ≥40px height on desktop and ≥36px on mobile. The `Logo` component (`components/shared/Logo.tsx`) handles this automatically.

## Favicon

Served as a static SVG (`app/icon.svg`) using the real Vantage symbol — scales crisply at every size. Apple touch icon generated by `app/apple-icon.tsx` (180×180 PNG) using the brand teal.

## Watermark

Use the monochrome-white symbol at 20% opacity, minimum 80px, in the corner of photographs only when the photograph is used in Vantage-owned materials (not partner materials without agreement).

## Logo misuse — never

- Stretch or compress the logo
- Rotate or skew
- Recolour with unapproved colours
- Add shadows, glows, or outlines
- Place on visually noisy backgrounds
- Place too close to other content (violate clear space)
- Separate the symbol from the wordmark
- Recreate with different fonts
- Place inside arbitrary shapes

## SVG spec (for future updates)

> **The current SVG logos were delivered and accepted on 2026-07-26.**
> They are true vector files (under 15 KB each, `<path>` geometry, text
> converted to outlines, correct viewBox, accessible `<title>`/`<desc>`).
>
> An earlier batch was rejected because the files were raster images embedded
> in an SVG wrapper (base64 `<image>` tags, 2.4–2.7 MB each, zero `<path>`
> elements). The spec below exists to prevent a recurrence if the logos are
> ever updated or new variants are added.

### Requirements for acceptable SVG deliverables

1. **True vector geometry only.** Trace the symbol and wordmark as paths. No
   embedded raster data (`<image>` tags, `data:image/...` URIs). The file must
   scale crisply from 24px to signage size with no pixelation.
2. **Text converted to outlines** (`<path>`), so the SVG has no font dependency.
3. **Exact brand colours:** Deep Teal `#007D8A`, Ocean Blue `#005B7A`, Dark Navy
   `#08233A`, White `#FFFFFF`. Sample from the PNG and match within ±2%.
4. **Optimised with SVGO** (or equivalent) — strip metadata, comments, editor
   namespaces, and unused defs. Target file size **under 50 KB** per variant.
5. **`viewBox` set correctly** with no fixed `width`/`height` attributes (so
   consumers can scale via CSS). Example: `viewBox="0 0 1448 1086"`.
6. **`role="img"` and `<title>`/`<desc>`** for accessibility.
7. **Provide all variants** listed in the "Required variants" table above.
8. **Verify at 24px, 64px, and 256px** — adjust path simplification if detail
   is lost at small sizes. The symbol must remain recognisable at 24px.

### How to check your work before submitting

Open the SVG in a text editor and confirm:
- ✅ Contains `<path>` elements
- ❌ Does **not** contain `<image` or `data:image`
- ✅ File size is under 50 KB
- ❌ Does **not** contain `base64`

If any of the ❌ checks fail, the file is a raster-wrapped SVG and will be
rejected. Re-export from a vector source (Illustrator, Figma, Inkscape) using
"Save As SVG" or "Export SVG" with "Convert text to outlines" enabled — not
"Export as PNG" wrapped in SVG.

## Implementation

The `Logo` component (`components/shared/Logo.tsx`) is the single integration
point. To swap PNG→SVG, update the `logoSrc` map in that file — no other code
changes required.
