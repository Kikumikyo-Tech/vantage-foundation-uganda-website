## Quick start for non-designers

1. **Which logo?** Header/signature → horizontal. Report cover/poster → primary stacked. Favicon/social profile → symbol only.
2. **Which colours?** White background, teal for buttons/links, navy for text. Use programme accent colours only to categorise a programme area.
3. **Which font?** Inter (web) or Aptos/Helvetica Neue/Arial (fallback). Never distribute proprietary font files.
4. **Which photos?** Real Vantage Foundation field photos from `content/media.ts`. Always include alt text and verify consent status.
5. **What never to change?** The logo symbol, the teal identity, the organisation name spelling, and the tagline.

See [asset-governance.md](./asset-governance.md) for the approval process.
